# ADR-007: Slugs are ASCII-only, no transliteration

**Status:** Accepted

The legacy router only accepts `[a-z0-9-]` in path segments. We looked at
transliterating (`é` → `e`) but it produced collisions with existing slugs
that are already indexed by search engines. Decision: non-ASCII characters
are dropped. `slugify('Café')` returning `'caf'` is expected.
